# 📈 Impacto no NPS

## 🎯 Resumo
Este projeto contribuiu diretamente para a recuperação do NPS de um stakeholder crítico.

## 📊 Evolução
- **Julho/2025**: NPS de 35,77
- **Setembro/2025**: NPS de 61,32

## 🔍 Como foi feito
- Mapeamento automatizado de causa raiz
- Identificação de alavancas de reversão
- Acompanhamento diário com dashboards e insights acionáveis
